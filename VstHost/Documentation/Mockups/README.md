# Tone Designer mockups

These are visual proposals, not implemented UI or approved requirements.

Current direction after feedback: **06-simplified-song-panel.png**. Keep the existing
pedalboard, library, browser and draggable divider. Use a temporary Song tones panel
for Base/A-D assignments and audition. Keep Follow song contextual to audition.

01-03 explore the initial editor, song assignments and section audition.
04-05 explore a zoomable node canvas; the user found the added UI over-engineered.
Those explorations do not authorise implementing a node editor or a new mode system.
Generated labels and effect controls are illustrative. Under Revision 3 there are no
on-board controls: pedals open the bundled NAM and Airwindows Consolidated plugins'
own windows, like any VST3.
